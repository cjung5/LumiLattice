LIBRARIES

The repository does not contain copies of its libraries. The package managers install them from
backend/uv.lock and frontend/package-lock.json, unchanged. Each package keeps its own license.

Most are MIT, BSD, ISC, or Apache-2.0. These are the main ones the app uses directly:
  3Dmol.js (BSD-3-Clause), pymatgen (MIT), Next.js (MIT), React (MIT), next-intl (MIT),
  d3-geo (ISC), topojson-client (ISC), FastAPI (MIT), SQLAlchemy (MIT)
  world-atlas (ISC), with map data from Natural Earth (public domain)
  Geist font (SIL Open Font License 1.1), through next/font
  CHGNet (BSD-3-Clause), for a local install only

These have a weak copyleft license, and the app uses them as unchanged libraries:
  psycopg, psycopg-binary (LGPL-3.0), the Postgres driver
  ase (LGPL-2.1-or-later), for the optional local relaxation
  bibtexparser (LGPL-3.0 or BSD), a dependency of pymatgen
  sharp-libvips (LGPL-3.0-or-later), an optional image library of Next.js
